# A股指数估值红绿灯

在线地址：<https://linhj888.github.io/ashare-valuation/>

用 **PB（市净率）十年百分位** 把指数分为三档，辅助判断买入时机：

- **低估**：PB 分位 < 30
- **正常**：30–70
- **高估**：PB 分位 > 70

覆盖：上证50、沪深300、中证500、创业板50。数据截至 **2026-10-31**，每月更新。

## 为什么用 PB

比较了 PE(TTM)、PE(静态)、PB、ERP、股息率及组合后，PB 在四个指数上都保持“低估 → 高估、未来收益递减”的单调性；PE 在中证500/创业板会出现“正常区比低估区收益更高”的失真，主要受盈利周期影响。因此用 PB 作为唯一主指标，PE 分位只作参考。

历史验证（未来 1 年平均总收益）：

| 指数 | 低估 | 正常 | 高估 |
|---|---|---|---|
| 上证50 | +15.4% | -3.4% | -12.2% |
| 沪深300 | +16.6% | -4.9% | -12.1% |
| 中证500 | +14.1% | +8.6% | -19.2% |
| 创业板50 | +37.4% | +22.1% | +14.9% |

创业板50 高估区未来 1 年仍为正（+14.9%），但未来 3 年平均 -18.9%。样本为重叠的月度观测，仅作历史统计，不代表未来。
